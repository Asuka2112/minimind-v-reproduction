# 中文图片问答评测

服务器任务和工作目录均命名为「评测」。

本轮已完成并通过文件与预测完整性核查。真实图片的语义判定和提示对照见 [验收结论](验收结论.md)。

这轮包含 152 题和 76 个图片对。128 题是有明确标签的程序生成图形，24 题使用此前外部评测的真实图源，其中 3 道题使用原图的水平镜像。真实子集共包含 21 张未变换的图片，题目与答案为这轮新编写。实拍图源复用此前报告的训练图片重合筛查结果。两类图片的分数分别报告。

每对图片的题目相同，正确答案不同。官方权重与本次复现权重均使用普通中文问法和追加短答要求的问法，在原图、同题换图、无图条件下生成。两种提示是预先固定的对照，推理预算为 192 token。模型不接收参考答案。

主指标是归一化短答匹配。完整回答与生成 token 保存在原始预测中。真实图片额外生成盲审文件，按语义正确性、明显矛盾和主要幻觉进行验收时，先看 review.json 里的图、题、答案和预测，再用 review_key.json 还原模型、提示和条件。短答匹配、语义评分和长度上限命中率各自提供不同证据。

查看后台状态：

```bash
ssh research-gpu 'cat /workspace/projects/评测/status.json'
```

结果包括冻结的 protocol.json、题图与原始预测、按条件和子集统计的 scores、按图片对抽样的差值区间、模型运行回执，以及真实图片复核清单。状态为 complete 后可同步到本机验收。程序生成样本用于诊断基础视觉能力，定向挑选的真实子集用于检查案例，二者规模及来源均限制了向一般中文问答场景的外推。
