# 原训练数据与新测试集审查

从实际训练的 2,904,511 行 SFT 文件均匀抽取 100 行，固定 seed 1726。全量源文件哈希与原训练记录一致。抽样结果用于提出数据调整假设。

| 观察项 | 样本数 |
| --- | ---: |
| 问题含中文字符 | 47 |
| 回答超过 100 字符 | 100 |
| 回答在 16 字符以内 | 0 |
| 按规则识别为描述 / 颜色 / 计数 / 位置题 | 17 / 3 / 2 / 2 |
| 单个图像占位符且图可解码 | 95 |
| 无图像占位符且为纯色图 | 5 |
| 图像解码失败 | 0 |

题型计数用关键词估计，其余 76 条仍可包含视觉问题。纯色图和无占位符对应的样本应作为文本样本单独理解。该结果说明抽到的样本均以长回答为主，为后续短答监督提供了实验动机。模型失败原因仍要用匹配续训对照验证。

新数据从 4,952 张 COCO 验证照片的镜像快照构建。前序训练近似图筛查移除 1,367 张候选，标签构造筛除 376 张，另在首次预检中排除 5 张视觉目标疑义图。最终冻结后，在模型结果生成前单独抽查四类各 6 个图片对。48 图中对 10 图标记了主色指代、局部可见人体或密集遮挡等歧义。主结果仍保留固定 240 题，同时检查这些配对对结论的影响。

审计明细见 [原 SFT 抽样统计](audit.json)、[测试标签抽查](test_label_review.json) 与 [冻结数据清单](../data/manifest.json)。
