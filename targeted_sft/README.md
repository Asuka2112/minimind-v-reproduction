# 定向中文视觉问答续训

研究问题是增加中文计数和空间题的监督，能否改善直接回答与图像依赖，同时保留中文文本能力。原项目的训练、导出和部署记录入口为 [项目进度](../项目进度与实习准备.md)。

已完成首种子和盲审交付，结果见 [实验结论](实验结论.md)，求职版本见 [简历与面试材料](简历与面试材料.md)。

## 固定实验

| 项目 | 设计 |
| --- | --- |
| 原 SFT 数据审查 | 均匀抽查 100 行，保留问题、回答、纯色图、长度与题型的审计记录 |
| 开发 / 测试 | 80 / 240 道，分别对应 40 / 120 个同题异答案图片对，均衡覆盖物体、颜色、计数和左右位置 |
| 测试图源 | COCO 2017 真实照片，添加框线区分目标。颜色按掩码主色，计数按实例标注。属于自行构造的带框问答，分数适用于此分布 |
| 数据隔离 | 按原图 ID、解码 RGB 与 dHash 近似图筛查，训练与两份测试互斥。原官方视觉数据也做相同查重，基础模型历史训练来源不可完全核查 |
| 常规组 / 定向组 | 各 2,048 条，使用同一图像序列和同一自训 SFT 起点。定向组将 800 条物体识别问题换成 400 条计数及 400 条空间关系。两组答案均简短 |
| 更新 | 1 GPU 每组，BF16，批量 16，micro-batch 8 累积两次，2 轮共 256 更新，学习率 5e-5，训练范围为投影加 LLM 首尾层 |
| 输入条件 | 原图、配对换图、无图。冻结贪心解码，同一序列检查 192 和 384 token 两个预算 |
| 决策 | 定向相对常规语义增益 ≥5 个百分点，短答合规增益 ≥10，同一图片对两张都答对比例的增益的 95% 区间下界 >0。中文文本 100 条回归相对基线及常规组下降均 ≤2 个百分点。首种子过门才复核第二种子 |

先以 32 条定向样本过拟合验证占位、标签和学习链路。语义主评分为规则解析，保留冻住的原始输出与随机抽样的匿名回答，供人工或 Codex 复核。统计重复与矛盾及保守的附加幻觉筛查。实际视觉幻觉的核实以抽查为准。

## 运行和复查

服务器任务名为「评测」，工作目录为 `/workspace/projects/评测/定向续训`。目录内的工作进程从父目录 `runtime` 使用已安装的 Python 环境。

1. 将固定的 COCO Parquet 和标注放进 `coco/`。URL 和哈希见 `common.py`、`build_data.py`。
2. 在服务器目录执行 `../runtime/bin/python audit_data.py`、`../runtime/bin/python build_data.py`。
3. 执行 `../runtime/bin/python freeze_protocol.py`，保存将要运行的训练、数据、评测和门槛。
4. 从该目录执行 `nohup ../runtime/bin/python -u run.py > 评测.log 2>&1 </dev/null &`。
5. 在 `status.json` 查询状态。子任务回执、原始输出、结果及抽查文件分别位于 `receipts/`、`predictions/`、`test-results-*.json`、`review-*.jsonl`。

公开来源：[COCO 项目](https://cocodataset.org/) · [数据镜像](https://huggingface.co/datasets/detection-datasets/coco/tree/cf0b22332314a937e9dc8a1957b21725430bb41d) · [实例标注镜像](https://huggingface.co/datasets/merve/coco/tree/9e50abcdc1361852f34841af4939cbcd2d37c92f)。按原数据图片许可使用。
