# 可用于简历的事实与边界

以下表述对应实际完成的工程；模型能力结论请同时阅读独立评测报告。

**项目名称：MiniMind-V 多模态模型全流程复现与独立评测**

- 基于 MiniMind-V 官方源码，搭建 SigLIP2 视觉编码器、MLP 投影和 65M 级语言解码端的图文问答系统，完成本机图片问答 WebUI、命令行推理与模型导出。
- 使用 4×RTX 4090 跑通 127.5 万图文预训练样本和 290.5 万图文指令样本的两阶段全量训练，每阶段 2 epoch；记录数据、权重与代码版本，完成 DDP、断点恢复验证和 Safetensors 导出一致性核查。
- 建立外部 MMStar 1,500 题、四模型三种图片条件的 12 组对照评测，保留 18,000 条原始预测；核查全部 417.9 万行视觉训练源数据的图片重合，区分生成正确率、格式合规率与强制选项诊断，并用按图片聚类的配对 bootstrap 估计差值区间。
