# 是否需要重新训练：复核意见

当前建议：先补齐适配评测与训练诊断，再决定是否重训。现有低分不足以支持立即重复整轮训练。

本次严格单字母生成的 0/1,500，是固定英文选择题及输出格式协议下的结果。官方发布模型也为 0/1,500。复核原始回答发现，官方模型在 mmstar-0050 的回答包含正确的 “option (A)”，但因生成了完整句子而被严格格式和官方前缀规则计错。因此，0 分不能被解读为所有图片的语义回答都错误。

上一轮 max_new_tokens=16 适合测试直接输出选项的能力，不能充分覆盖完整开放式问答。本次 SFT 有 1,499/1,500 条原图回答达到长度上限，官方模型为 1,496/1,500。仓库原生 eval_vlm.py 默认允许 512 token，并使用中文图片描述提示。此前对整体模型质量的判断需要受此限制；原始协议和分数保留，不据新解释改写已有成绩。

另有部分 MMStar 题目的选项字段包含 nan，实际有效选项不足四个。原报告的 A–D 首位置概率是固定四字母诊断，不能替代按有效选项评分的完整选择题评测。始终选 B 为29.80%的描述性参照仍成立。

训练记录已验证正式更新次数、可训练参数变化、冻结参数不变、有限值及导出一致性。这些证据支持训练实际执行和产物完整性，尚不能排除标签、图像对齐、训练配置或任务适配上的效果问题。当前没有发现足以直接要求从头重跑的实现故障。

后续应先固定新的一批中文图片问答题及评分标准，允许128–512 token完整输出，对比本次模型与官方模型，并保留换图、无图对照。概念上需分别观察：回答内容正确性、格式遵循、终止/重复、图像依赖。该新增评测需另立协议，不能据MMStar答案调提示后冒充原测试结果。中文算术64题同样普遍截断，暂不据此宣称一般语言能力丧失。

重训决策：

- 若发现图像输入、标签掩码、特殊token或权重加载错误，先修复并用少量样本验证能学会，再启动正式训练；是否从语言基座或中间检查点开始，取决于错误影响范围。
- 若推理正常但相关任务表现弱，先做有独立验证集的小规模定向SFT实验，比较数据、冻结策略或学习率；实验有效后再扩展全量训练。
- 若官方模型在同样适配评测中也表现相近，应优先判断65M级模型和现有数据能否满足目标。重复相同数据、配置和轮数没有已知的改进依据；更大基座或更合适数据应作为单独实验，而非称为原项目复现。

可核对文件：protocol.json、EXAMPLES.md、summary.json、training/results/results.json，以及本仓库 eval_vlm.py 第41行的默认生成长度。此意见未启动新训练，也未改动已冻结的实验和原始预测。
